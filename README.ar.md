# متتبع المهام والتركيز Masarifi

نموذج أولي عربي ومتوافق مع الهواتف للإنتاجية، يجمع بين قائمة مهام محفوظة ومؤقت للتركيز وإحصاءات للجلسات وإنجازات قابلة للفتح. نُفذت الواجهة باستخدام JavaScript دون إطار عمل وTailwind CSS.

## المزايا المنفذة

- إضافة المهام وإكمالها وحذفها
- تصفية جميع المهام أو الجارية أو المكتملة
- مسح المهام المكتملة دفعة واحدة
- حفظ المهام في التخزين المحلي للمتصفح
- بدء جلسات التركيز وإيقافها مؤقتًا وإنهاؤها
- تتبع عدد الجلسات والوقت الإجمالي محليًا
- فتح ستة إنجازات وفق مدة الاستخدام وعدد الجلسات
- واجهة عربية متجاوبة باتجاه RTL
- واجهة تسجيل دخول وإنشاء حساب مهيأة لاستخدام Supabase Auth
- خادم ملفات ثابت بسيط باستخدام Node.js

## التقنيات المستخدمة

- HTML5
- Tailwind CSS عبر CDN
- JavaScript ووحدات ES دون إطار عمل
- التخزين المحلي للمتصفح
- Supabase JavaScript Client لهيكل تسجيل الدخول
- خادم HTTP المدمج في Node.js

## بنية المشروع

```text
Masarifi_VB_Coding/
├── index.html       # صفحة قائمة المهام
├── timer.html       # المؤقت والإحصاءات والإنجازات
├── login.html       # واجهة تسجيل الدخول وإنشاء الحساب عبر Supabase
├── server.js        # خادم ملفات ثابت للتشغيل المحلي
├── css/style.css    # التنسيقات المخصصة
├── js/
│   ├── app.js       # عمليات المهام والتصفية والحفظ المحلي
│   ├── timer.js     # المؤقت والإحصاءات والإنجازات
│   ├── auth.js      # دوال تسجيل الدخول عبر Supabase
│   └── config.js    # قيم إعداد Supabase التجريبية
└── Rules.md         # موجز المنتج الأصلي
```

## تشغيل المشروع محليًا

يتطلب التشغيل Node.js، ولا توجد حزم تحتاج إلى تثبيت.

```bash
git clone https://github.com/mohammadimad/Masarifi_VB_Coding.git
cd Masarifi_VB_Coding
node server.js
```

افتح `http://localhost:8081/` لقائمة المهام أو `http://localhost:8081/timer.html` للمؤقت.

## إعداد تسجيل الدخول

يحتوي `js/config.js` على قيم تجريبية. لتجربة صفحة تسجيل الدخول، أنشئ مشروع Supabase واستبدل رابط المشروع العام والمفتاح المجهول فقط:

```js
const SUPABASE_URL = "YOUR_SUPABASE_URL_HERE";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY_HERE";
```

لا تضع مفتاح `service-role` في كود الواجهة الأمامية، واضبط سياسات Row Level Security قبل ربط بيانات المستخدمين.

## التحقق

اجتاز الخادم ووحدات JavaScript فحص الصياغة باستخدام Node.js. يحتوي المستودع على قيم إعداد تجريبية لـSupabase ولا يحتوي على بيانات اعتماد منشورة.

## النطاق الحالي

- التنفيذ الحالي متتبع للمهام والتركيز، رغم أن `Rules.md` يصف فكرة سابقة لإدارة المصاريف الشخصية.
- تُحفظ المهام وإحصاءات المؤقت والإنجازات داخل المتصفح الحالي فقط.
- يحتاج تسجيل الدخول عبر Supabase إلى الإعداد، وهو غير مربوط ببيانات المهام أو المؤقت.
- لا تفرض صفحتا المهام والمؤقت جلسة Supabase حاليًا.
- لا يوجد تنفيذ لتتبع الدخل أو المصروفات.

## تحسينات مقترحة
