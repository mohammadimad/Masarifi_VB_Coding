# مصاريفي (Masarifi) - متتبع المصاريف والدخل الشخصي

تطبيق ويب عصري ومتجاوب لإدارة الأموال والمصاريف الشخصية باللغة العربية، مبني باتجاه اليمين إلى اليسار (RTL) وفقاً لدليل التصميم المستخرج من **Google Stitch** وقواعد المنتج في `Rules.md`، ومطور وفق منهجية **SCOPE**.

يتيح التطبيق للمستخدمين تتبع المصروفات الشهرية، والاطلاع على لوحة تحكم تفاعلية تلخص العمليات والرصيد المتبقي والميزانية المحددة وإجمالي المصروفات للشهر الجاري، مع شريط تقدم ذكي لاستهلاك الميزانية.

---

## المزايا الرئيسية

- **لوحة تحكم إحصائية ذكية:**
  - عرض فوري للرصيد المتبقي من الميزانية، إجمالي الميزانية المحددة، وإجمالي المصروفات للشهر الحالي.
  - شريط تقدم ديناميكي لاستهلاك الميزانية (`Progress Bar`) يتحول تلقائياً إلى اللون الأحمر التحذيري عند تجاوز الميزانية (أكثر من 100%).
  - احتساب ديناميكي يبدأ تلقائياً من اليوم الأول في الشهر وينتهي بآخر يوم من الشهر، وتجاهل أي عمليات خارج هذا النطاق كأرشيف.
- **إدارة العمليات والمصروفات (CRUD):**
  - إضافة مصروف جديد مع التحقق من صحة المدخلات وتطهيرها (منع الأرقام السالبة والقيم الفارغة).
  - حذف أي مصروف بنقرة واحدة مع تحديث فوري لعناصر الصفحة وقاعدة البيانات دون إعادة تحميلها.
  - تنسيق آلي للتواريخ: عرض "اليوم" للعمليات المضافة اليوم، و"أمس" للأمس، أو بصيغة `YYYY-MM-DD`.
  - إشعارات تفاعلية منبثقة (Toasts) فورية لعمليات الإضافة والحذف ورسائل الأخطاء.
- **عزل تام للطبقات (Pattern Logic):**
  - فصل منطق استعلامات قاعدة البيانات (`db.js`) تماماً عن منطق عرض وتحديث الواجهة (`ui.js`).
  - تعليقات عربية مفصلة وشاملة في كافة الملفات لتسهيل الفهم على المطورين المبتدئين.
- **نظام مصادقة المستخدمين وحماية المسارات:**
  - صفحة تسجيل دخول وإنشاء حساب أنيقة (`login.html`) بشعار مصاريفي الرسمي.
  - حارس الجلسة (`Session Guard`): تحويل المستخدم غير المسجل إلى صفحة الدخول، وإعادة المسجل تلقائياً إلى لوحة التحكم.
  - ربط كامل مع **Supabase Auth** و **Row Level Security (RLS)** مع وضع تجريبي احتياطي (Demo Fallback) للتجربة المحلية الفورية.
- **تصميم مطابق لـ Google Stitch:**
  - متوافق مع كافة الشاشات (الهواتف الذكية مع شريط علوي، والأجهزة اللوحية والمكتبية مع شريط جانبي ثابت).

## التقنيات المستخدمة

- **HTML5** بالاتجاه العربي `dir="rtl"`.
- **Tailwind CSS** مع إعدادات نظام التصميم المستخرجة من Google Stitch.
- **JavaScript (ES6+) نقي (Vanilla JS)** دون أي أطر عمل أو مجمّعات كود (No npm, No Bundler).
- **Supabase JavaScript Client** عبر CDN الرسمي (`@supabase/supabase-js@2`).
- **خادم محلي خفيف** مبني بـ Node.js المدمج بدون أي حزم خارجية.

## هيكل المشروع

```text
Masarifi_VB_Coding/
├── index.html                           # لوحة التحكم الرئيسية وإدارة العمليات
├── login.html                           # صفحة تسجيل الدخول وإنشاء الحساب
├── budget.html                          # صفحة إدارة الميزانيات التفصيلية
├── supabase_schema.sql                  # كود إنشاء الجداول وسياسات الأمان RLS في Supabase
├── assets/
│   ├── logo.png                         # الشعار الرسمي لتطبيق مصاريفي
│   └── js/
│       ├── config.js                    # تهيئة عميل Supabase وقراءة متغيرات البيئة
│       ├── auth.js                      # المصادقة، تسجيل الدخول، وحراس الجلسة (Session Guard)
│       ├── db.js                        # استعلامات الشهر الحالي، المصروفات، والميزانية المعزولة
│       ├── ui.js                        # طبقة رسم العناصر، شريط التقدم، الإشعارات المنبثقة
│       └── app.js                       # المنسق العام للوحة التحكم
├── js/                                  # إعادة تصدير الوحدات للتوافق مع كافة المسارات
├── css/
│   └── style.css                        # التنسيقات العامة ومتغيرات لوحة الألوان والأيقونات
├── server.js                            # خادم محلي لتشغيل المشروع على المنفذ 8082
└── Rules.md                             # وثيقة مواصفات وقواعد المنتج الأصلية
```

## تشغيل المشروع محلياً

لا يتطلب تشغيل المشروع أي تثبيت لحزم خارجية (`npm install` غير مطلوبة):

```bash
# تشغيل الخادم المحلي
node server.js
```

ثم افتح المتصفح على:
- لوحة التحكم: [http://localhost:8082/index.html](http://localhost:8082/index.html)
- تسجيل الدخول: [http://localhost:8082/login.html](http://localhost:8082/login.html)

## إعداد قاعدة بيانات Supabase

يعمل المشروع محلياً وتلقائياً بنمط التخزين المحلي في حال عدم ضبط المفاتيح. لتفعيل قاعدة البيانات السحابية:
1. افتح مشروعك في [Supabase](https://supabase.com).
2. افتح محرر الـ SQL في Supabase والصق محتويات الملف `supabase_schema.sql` لتنفيذ إنشاء الجداول (`profiles` و `expenses`) وسياسات الـ RLS.
3. افتح الملف `assets/js/config.js` وضع رابط مشروعك ومفتاح `anon`:
   ```javascript
   export const SUPABASE_URL = "https://your-project.supabase.co";
   export const SUPABASE_ANON_KEY = "your-anon-key";
   ```
