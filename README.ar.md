# مصاريفي (Masarifi) - متتبع المصاريف والدخل الشخصي

تطبيق ويب عصري ومتجاوب لإدارة الأموال والمصاريف الشخصية باللغة العربية، مبني باتجاه اليمين إلى اليسار (RTL) وفقاً لدليل التصميم المستخرج من **Google Stitch** وقواعد المنتج في `Rules.md`. 

يتيح التطبيق للمستخدمين تتبع الدخل والمصروفات اليومية، والاطلاع على لوحة تحكم تفاعلية تلخص العمليات والرصيد الحالي وإجمالي الدخل وإجمالي المصروفات للشهر الجاري.

---

## المزايا الرئيسية

- **لوحة تحكم إحصائية ذكية:**
  - عرض فوري للرصيد الحالي، إجمالي الدخل (بالأخضر)، وإجمالي المصروفات (بالأحمر).
  - احتساب الأرقام وتحديثها ديناميكياً وفورياً عند إضافة أو تعديل أو حذف أي معاملة.
- **إدارة العمليات المالية (CRUD):**
  - إضافة عملية جديدة (مصروف أو دخل) مع تحديد المبلغ، التصنيف، والتاريخ.
  - إمكانية تعديل أي عملية سابقة أو حذفها بنقرة واحدة.
  - أيقونات ملونة وتصنيفات متعددة (البقالة والتسوق، طعام، مواصلات، فواتير، راتب، صحة، وغيرها).
- **نافذة تفاعلية (Modal Popup):**
  - نافذة منبثقة وسط الشاشة مع خلفية ضبابية (`backdrop-blur`) لإضافة وتعديل العمليات بسلاسة.
- **نظام مصادقة المستخدمين:**
  - صفحة تسجيل دخول وإنشاء حساب أنيقة (`login.html`) بشعار مصاريفي الرسمي.
  - مهيأة للربط المباشر مع **Supabase Auth** مع دعم وضع تجريبي تلقائي (Demo Fallback) للتجربة المحلية بدون إعداد مسبق.
- **تصميم مطابق لـ Google Stitch:**
  - تم نقل وتطبيق الألوان الرسمية (`#3525cd` و `#4f46e5` و `#fcf8ff`) والخطوط (`Cairo` و `Inter`) وأيقونات Google Material Symbols.
  - متوافق مع كافة الشاشات (الهواتف الذكية مع شريط علوي، والأجهزة اللوحية والمكتبية مع شريط جانبي ثابت).

---

## التقنيات المستخدمة

- **HTML5** بالاتجاه العربي `dir="rtl"`.
- **Tailwind CSS** مع إعدادات نظام التصميم المستخرجة من Google Stitch.
- **JavaScript (ES6+) نقي (Vanilla JS)** دون أي أطر عمل أو مكتبات ثقيلة، وباعتماد وحدات ES Modules.
- **Supabase JavaScript Client** لإدارة الحسابات وقاعدة البيانات.
- **خادم محلي خفيف** مبني بـ Node.js المدمج بدون أي تبعيات خارجية (Zero Dependencies).

## تشغيل المشروع محلياً

لا يتطلب تشغيل المشروع أي تثبيت لحزم خارجية (`npm install` غير مطلوبة):

```bash
# تشغيل الخادم المحلي
node server.js
```

ثم افتح المتصفح على:
- لوحة التحكم: [http://localhost:8081/index.html](http://localhost:8081/index.html)
- تسجيل الدخول: [http://localhost:8081/login.html](http://localhost:8081/login.html)

## إعداد قاعدة بيانات Supabase (اختياري)

يعمل المشروع محلياً بشكل فوري باستخدام التخزين المحلي للمتصفح. لربطه بقاعدة بيانات Supabase سحابية:
1. افتح مشروعك في [Supabase](https://supabase.com).
2. افتح الملف `js/config.js` وضع رابط مشروعك ومفتاح `anon`:
   ```javascript
   export const SUPABASE_URL = "https://your-project.supabase.co";
   export const SUPABASE_ANON_KEY = "your-anon-key";
   ```
